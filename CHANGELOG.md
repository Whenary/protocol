# Changelog

## [0.1.1] (2026-11-05)

### Added

- `identityEpochPayload`: `whenary:identity-epoch:v1` statement for an identity-key rotation

## [0.1.0] (2026-09-12)

### Added

- `protocol.ts`: E2EE envelope formats (e2ee1/e2ee2/e2ee2n/e2ee2meta), AAD constructors, and parsers
- `primitives.ts`: HKDF-SHA-256, AES-256-GCM, X25519, XEdDSA, key seal/open via `@noble/curves` and `@noble/hashes`
- Apache-2.0 license with patent grant
